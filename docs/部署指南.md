## 一、必须先理解的一件事：bgm.tv 被墙

这跟「网站部署在哪」是**两个独立的问题**，很容易混在一起想：

| 问题 | 说明 |
| --- | --- |
| **A. 网页本身能不能打开** | 取决于托管平台的域名国内可达性 |
| **B. 网页能不能取到番剧数据** | 取决于 `api.bgm.tv` / `lain.bgm.tv` 是否可达 |

**A 解决了不代表 B 解决了。** 网页能秒开，但搜索框照样可能搜不出东西。

实测你所在网络：

| 目标 | 直连 | 走代理 |
| --- | --- | --- |
| `api.bgm.tv` | ❌ 超时 15 秒 | ✅ 200 / 0.57 秒 |
| `lain.bgm.tv` | ❌ 超时 15 秒 | ✅ 200 / 0.51 秒 |
| `www.baidu.com` | ✅ 0.41 秒 | — |

而且 DNS 也污染了：本机把 `lain.bgm.tv` 解析到了 `31.13.112.9`（Facebook 的 IP 段）。

### 所以怎么用

1. **设备上开着代理** —— 搜番、取海报都正常，这是当前的主要用法
2. **不想开代理** —— 直接上传自己的海报图，标题和评分手动填，功能一样完整
3. 搜不到番时页面底部会明确提示「连不上 bgm.tv，请打开代理或改用上传图片」，不会静默失败

> 之前版本做过「中转服务」（把请求转发到墙外的 Cloudflare Worker 绕开限制），
> 因为主要是自用、设备上一直有代理，已经移除了，少一层维护。

## 二、托管平台（问题 A）

当前用 GitHub Pages。它的默认域名 `*.github.io` 在国内**可用性有波动**，
不算稳定，但自用够用。如果哪天发现打不开，换下面这个：

### 推荐备选：腾讯云 EdgeOne Pages（免备案）

目前少数能同时满足「国内可访问 + 免备案 + 不用命令行」的免费方案。

1. 打开腾讯云 <https://cloud.tencent.com/> 注册并完成**实名认证**
2. 进入 **EdgeOne Pages** 控制台
3. 选**直接上传**，把站点文件拖进去：`index.html`、`styles.css`、`js/`、`fonts/`、`.nojekyll`
   （不要传 `tools/`、`docs/`、`.git/`，那些是开发用的）
4. 得到 `*.edgeone.app` 之类的网址，手机电脑都能开

> 注意：**不用大陆加速节点**时，EdgeOne 分配的是走海外节点的二级域名，**不需要备案**。
> 如果要绑自己的域名并开大陆加速，那就**必须完成 ICP 备案**。

### 其他备选

| 平台 | 国内访问 | 需要备案 | 操作方式 |
| --- | --- | --- | --- |
| Cloudflare Pages | ⚠️ 时通时断 | 免 | 拖拽上传，或连 GitHub |
| Vercel | ⚠️ 慢/常失败 | 免 | 拖拽上传，或连 GitHub |
| Netlify | ⚠️ 较差 | 免 | 拖到 app.netlify.com/drop |
| 阿里云 OSS / 腾讯云 COS | ✅ 很快 | **必须备案** | 上传后开静态网站 |

Vercel 官方知识库自己承认站点在中国大陆 "may load slowly or fail to load"：
<https://vercel.com/kb/guide/accessing-vercel-hosted-sites-from-mainland-china>

本项目已备好 `vercel.json`、`netlify.toml`、`.nojekyll`，都是「上传即可」，
不需要填构建命令（本项目没有构建步骤）。

## 三、部署后必须做的验收

**不要只看电脑。** 用手机在移动 / 联通 / 电信网络下至少各测一次：

1. ☐ 网址能打开（说明问题 A 满足）
2. ☐ 开着代理时能搜到番（说明问题 B 满足）
3. ☐ 点结果能出海报、能点「下载 PNG」
4. ☐ 下载的图能存进相册
5. ☐ 关掉代理时给出的是明确提示，而不是白屏或静默失败

任何一步不通，对照第一节那张表就能定位是 A 还是 B 的问题。

## 四、已知限制

- **海报清晰度**：图源是 `/r/800/`（长边不超过 800px），画布放大到 1080 宽时海报会被轻微放大。
  想要更清晰就用「上传自己的图片」。
- **微信内置浏览器**对未备案域名可能弹拦截提示；腾讯云社区有「已备案域名因同步延迟仍被提示」的反馈。
- **小红书 App 内打开第三方链接**通常受限，建议复制到系统浏览器打开。
- 本工具**不存储任何数据**，没有后端，图片和文字全部在浏览器里生成。
