# 番剧封面工坊

把 Bangumi（bgm.tv）的番剧海报，包装成可以直接发小红书的吐槽图。

搜番名 → 选主题 → 填自己的评分和角标 → 下载 PNG。手机、电脑都能用。

**在线地址：<https://ijichinijika99.github.io/xhs_aoi-cover/>**

![主题数量](https://img.shields.io/badge/主题-5_套-4F46E5) ![配色](https://img.shields.io/badge/配色-8_套-E8452C) ![纯静态](https://img.shields.io/badge/后端-纯静态-1D9A6C)

## 它解决什么问题

以前发帖要自己把海报存下来，再想办法在图上写评分和感想。现在打开网页：

1. 输入番名，从 Bangumi 搜到条目，**标题、原名、年份、集数、制作公司、站内评分、海报全部自动填好**
2. 选一套主题（5 套山岳系列）和配色（8 套），再挑一座《向山进发》里的山
3. 点「下载 PNG」，得到一张 1080 × 1440 的竖版图，直接发

图片和文字**全部在你的浏览器本地生成**，不上传任何服务器，也没有后端。

## 本地打开（最省事）

**双击 `启动.bat`**，会自动挑一个没被占用的端口、起服务、并打开浏览器。
窗口里会打印电脑和手机两个地址，**关掉窗口就停止服务**。

需要先装 [Node.js](https://nodejs.org/)（一路点"下一步"即可）。
没装的话双击 `启动.bat` 会给出英文提示并停住，不会一闪而过。

也可以手动跑：

```bash
node launcher.mjs          # 自动挑端口 + 开浏览器
node launcher.mjs 9000     # 指定端口
node launcher.mjs --no-open  # 不自动开浏览器
node server.mjs 8080       # 只起服务，不挑端口也不开浏览器
```

然后访问 <http://127.0.0.1:8080/>。

同一 WiFi 下，手机也能用电脑的局域网地址打开（启动时会打印，形如 `http://192.168.x.x:8080/`）。

> 为什么不能直接双击 `index.html`？
> 因为页面用了 ES 模块，浏览器的 `file://` 协议会拦截模块加载，必须由一个小服务器提供。
>
> 顺带一提：`启动.bat` 特意写成**纯 ASCII**。中文 Windows 的 cmd 按 GBK 读取批处理文件，
> 如果 .bat 里直接塞 UTF-8 中文，字节错位会把后面的命令名吃掉（`if errorlevel` 会变成 `orlevel`），
> 表现就是窗口一闪而过。所以中文提示都由 Node 输出，Node 打印 UTF-8 是正常的。

## 部署到公网（手机随时能开）

这是**纯静态站点**，没有任何后端和构建步骤，整个文件夹丢上去就能用。

本项目**已经部署在 GitHub Pages 上**：<https://ijichinijika99.github.io/xhs_aoi-cover/>

`main` 分支一有推送，`.github/workflows/pages.yml` 就会自动发布。
这个 workflow 只上传站点运行需要的文件（`index.html` / `styles.css` / `js/` / `fonts/`），
所以线上体积约 **1.3 MB**，而不是仓库里的 30+ MB（`docs/` 里的主题示例图不算在内）。

想换平台的话，这些配置文件已经放好了，都是「上传即可」：

| 平台 | 配置文件 | 说明 |
| --- | --- | --- |
| 腾讯云 EdgeOne Pages | 无需 | 免备案、拖拽上传，**国内解析比 GitHub Pages 稳** |
| Vercel | `vercel.json` | 国内访问不稳定 |
| Cloudflare Pages | 无需 | 国内访问时通时断 |
| Netlify | `netlify.toml` | 拖文件夹到 app.netlify.com/drop |
| GitHub Pages | `.github/workflows/pages.yml` | 当前在用 |

> 注意：托管平台和「能不能访问 bgm.tv」是两件独立的事。
> 换托管平台不会让 bgm.tv 变得可访问。

## 5 套主题（山岳系列）

这一族主题的共同设计前提：**海报是主角**。满幅铺满或大块占据画面，标题、评分、吐槽直接叠压在图上，

## 可调选项

- **评分**：0–10，支持一位小数；可显示档位（神作 / 力荐 / 佳作 / 还行 / 一般 / 微妙 / 弃番）；可同时标注 Bangumi 站内评分与排名
- **角标文案**：左上角小标签，内置「新番速递 / 本月最强 / 补番推荐 / 完结吐槽 / 冷门神作 / 烂片警告 / 私藏片单 / 重温经典」，也能自己写
- **一句吐槽**：最多 3 行，自动断行
- **条目信息**：原名 / 年份 / 集数 / 制作公司 / 标签，可整体关闭，也可只留年份和制作
- **署名**：小红书号水印，或自定义页脚（如「每周三更新 · 番剧吐槽」）
- **比例**：3:4（1080×1440）/ 4:5（1080×1350）/ 9:16（1080×1920）/ 1:1（1080×1080）
- **导出宽度**：720 / 1080 / 1440
- **文字对齐**：跟随主题 / 统一左对齐 / 统一居中
- **颗粒质感**：可关

设置会自动存在浏览器本地，下次打开还是上次的样子。

## 技术要点（踩过的坑）

这几条决定了这个工具能不能用，记录备查：

1. **海报图必须走 `/r/` 端点。**
   `lain.bgm.tv/pic/cover/l/xxx.jpg`（原图）**不带 CORS 头**，画进 canvas 会污染画布，`toBlob()` 直接抛 `SecurityError`，导不出图。
   而 `lain.bgm.tv/r/800/pic/cover/l/xxx.jpg` **带 `Access-Control-Allow-Origin: *`**，可以正常导出。
   所以代码里统一用 API 给的 `images.medium`（即 `/r/800/`），并配 `img.crossOrigin = 'anonymous'`。
   `bgm.js` 里的 `corsImageUrl()` 负责兜底改写。

2. **`/r/` 只接受 100 / 200 / 400 / 600 / 800 / 1200。**
   单边尺寸是**等比缩放不裁剪**（实测 592×900 的原图取 `/r/800/` 仍是 592×900）。其它数值返回 400。

3. **搜索接口是 POST，但可以跨域。**
   `POST https://api.bgm.tv/v0/search/subjects` 带 `ACAO: *`，浏览器可直发。`limit` 服务端上限 20。
   空 User-Agent 或 undici / node-fetch 这类默认 UA 会被 403，浏览器自带的 UA 不受影响。

4. **未评分条目的 `rating.score` 是 `0` 而不是 `null`。**
   新番常见。不处理会显示成「我的评分 0.0」，所以 `bgm.js` 里把 `score > 0` 之外的一律当无评分。

5. **infobox 的 `value` 有三种形态**：裸字符串 / `[{v}]` 多值 / `[{k,v}]` 带子标签。`bgm.js` 的 `infoboxValue()` 全部兼容。

6. **字体用 unicode-range 分片自托管。**
   标题字是[得意黑 Smiley Sans](https://github.com/atelier-anchor/smiley-sans)（SIL OFL 1.1，允许商用与生成图片）。
   完整字体太大，这里用中文网字计划的 **80 个 woff2 分片（共 1.1 MB）**，浏览器只下载画面真正用到的几个分片，通常几百 KB。
   自托管也顺便避开了第三方 CDN 的 CORS 与版本变动风险。

7. **斜角角标不能用「无限长的 45° 带子」。**
   一条 45° 的带子只要与左上角相交，就必然横跨整个画布（几何必然，试了两版才想明白）。
   最后做成「有长度的斜牌」：起点伸到画面外，末端斜切收口，看起来才是贴在角上的标签。
   而且不靠 `ctx.rotate` 推断坐标系——先把矩形四角在局部坐标算好再逐个变换到画布坐标，
   每条边画在哪里都能直接验证。

8. **`.bat` 必须纯 ASCII。**
   中文 Windows 的 cmd 按 GBK 读批处理文件，UTF-8 中文会让字节错位、把后面的命令名吃掉
   （`if errorlevel` 变成 `orlevel`），表现就是窗口一闪而过。所以中文提示由 Node 输出。
   仓库里还加了 `.gitattributes`（`* -text`）锁住行尾，避免 Git 转换再次弄坏它。

9. **手机端预览降到 720 宽。**
   模糊底 + 1080×1440 画布在中低端手机上会卡。导出时仍按用户选的尺寸全分辨率重绘，成品不受影响。

## 项目结构

```
index.html            页面结构
styles.css            界面样式（桌面双栏 / 手机单栏 + 悬浮操作条 + 折叠面板）
server.mjs            零依赖本地静态服务器（含局域网地址筛选）
launcher.mjs          一键启动：挑空闲端口 → 起服务 → 开浏览器
启动.bat              Windows 双击启动（纯 ASCII，中文提示由 Node 输出）
vercel.json           Vercel 部署配置
netlify.toml          Netlify / Cloudflare Pages 部署配置
.nojekyll             GitHub Pages 跳过 Jekyll
.gitattributes        锁住行尾，防止 .bat 被转换破坏
.github/workflows/
  pages.yml           GitHub Pages 自动部署（只发布站点需要的文件）
js/
  app.js              界面逻辑与状态管理
  bgm.js              Bangumi 数据接入 + 跨域图片处理
  mountains.js        《向山进发》的山：海拔 / 经纬度 / 出现季数
  themes.js           5 套主题 + 8 套配色 + 信息排版内核
  core.js             信息区排版部件
  util.js             Canvas 绘图工具库
fonts/
  smiley.css          得意黑 @font-face（80 个 unicode-range 分片）
  *.woff2             字体分片
tools/
  shot.mjs            逐主题出图（开发用）
  shot-one.mjs        只渲染指定主题，改设计时快速迭代（开发用）
  shot-ui.mjs         截界面整图（开发用）
  e2e.mjs             端到端验证（开发用）
  check-live.mjs      线上站点可用性验证（开发用）
docs/
  部署指南.md          各平台部署步骤与国内可达性
  主题总览.html        5 套主题的成品示例
```

## 开发自检

```bash
# 逐主题出图，检查视觉
node tools/shot.mjs 400602 tools/shots 8080

# 只渲染某个主题（改设计时用，快很多）
node tools/shot-one.mjs 400602 aoi tools/shots 8080

# 端到端验证：真实搜索、真实下载、跨域污染、手机端布局
node tools/e2e.mjs

# 线上站点验证：模块加载、字体、资源 404、控制台报错
node tools/check-live.mjs
```

全部脚本都用 Chrome DevTools Protocol 驱动无头 Chrome，只依赖 Node 内置模块。

## 说明与边界

- 海报与条目数据来自 [Bangumi 番组计划](https://bgm.tv)，仅供个人发帖使用
- 海报取的是 `/r/800/` 缩放图（长边不超过 800px）。如果画布很大，海报会被轻微放大，这是跨域导出限制下的取舍。想用更清晰的图，直接点「或上传自己的图片」
- 搜番依赖设备上的代理（或者改用上传图片）；请求超时设为 12 秒，可以在 `js/bgm.js` 里调 `DIRECT_TIMEOUT`
- 本工具不存储任何数据；接口异常时以页面底部的状态提示为准
- GitHub Pages 的默认域名在国内可访问性有波动。如果发现打不开，把仓库连到腾讯云 EdgeOne Pages 重新发一次即可（同一套文件，不用改代码）
